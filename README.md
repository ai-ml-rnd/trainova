# Forge - Unified Data Platform for LLM & VLM Training

**Forge** is one platform where a team can build every dataset needed to train an LLM or VLM from scratch.

## Status

Phase 0 (Foundation) in progress.

## Quick Start

```bash
# Setup monorepo
make deps

# Start development
make dev
```
